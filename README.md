<h2 align="center">maxtgforumsbridge</h2>
<h2 align="center">Мост между аккаунтом макс и форумом Telegram.</h2>


Идея проекта — использовать Telegram Forum как интерфейс для общения с пользователями в максе.<br>
Эта идея витала в моей голове ещё давно, но руки никак не доходили для создания этого проекта,<br>
так-то уже существует много мостов между максом и telegram но на сколько мне известно, никто из них не использует "форумы"<br>
так-что, своего рода это "уникальный" проект.<br>

## Дисклеймер
maxtgforumsbridge использует готовое неофициальное api [pymax](https://github.com/MaxApiTeam/PyMax) а он в свою очередь использует неофициальный внутренний api макса.<br>
api может измениться без предупреждения, и, вследствии чего некоторые функции могут перестать работать без предупреждения. <br>
**Использование библиотеки и данного моста может нарушать условия сервиса.**<br>
Вы используете maxtgforumsbridge на свой риск. **За блокировку аккаунта отвечаете только Вы.**<br>
Проект все ещё находится в стадии "доработки" и я не могу обещать его стабильность.

## Что умеет этот ваш мост?

- 💬 Пересылает сообщения между MAX и Telegram в обе стороны
- 🧵 Автоматически создаёт отдельные темы для MAX-чатов
- 👥 Поддерживает групповые чаты с именами отправителей
- ↩️ Сохраняет ответы на сообщения и их связь между MAX и Telegram
- ✏️ Синхронизирует изменения и удаления сообщений
- 🖼️ Поддерживает медиа: фотографии, видео, видеокружки, голосовые и файлы
- 👍 Поддерживает реакции на сообщения
- 📢 Имеет служебную тему со статусами и системными сообщениями
- 📤 Позволяет первым написать пользователю MAX через `/send`
- 🔗 Позволяет вступать в MAX-группы по ссылке через `/join`
- 💾 Сохраняет чаты и их соответствие Telegram-темам после перезапуска

## Установка

1. Установите **Python 3.10 или новее**. [Python](https://www.python.org/downloads)

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Переименуйте `.env.example` в `.env` и заполните его:
```env
MAX_PHONE=+70000000000
TELEGRAM_BOT_TOKEN=
TELEGRAM_FORUM_CHAT_ID=-1000000000000

# Telegram ID пользователей, которым разрешены команды /send, /join и т.д.
# Можно оставить пустым, тогда команды будут доступны всем в форуме.
ALLOWED_TELEGRAM_USER_IDS=

MAX_WORK_DIR=data/max
MAX_SESSION_NAME=account.db
DB_PATH=data/bridge.sqlite3
LOG_LEVEL=INFO

# Необязательно: прокси для Telegram Bot API.
# Например: socks5://user:pass@host:port или http://host:port
TELEGRAM_PROXY=
```

4. Запустите:
```bash
python -m app
```

При первом запуске потребуется ввести SMS-код для входа в MAX. Сессия сохранится автоматически.
