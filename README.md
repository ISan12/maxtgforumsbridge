<h2 align="center">maxtgforumsbridge</h2>
<h2 align="center">Мост между аккаунтом макс и форумом Telegram.</h2>

Идея проекта — использовать Telegram Forum как интерфейс для общения с пользователями в максе.

Эта идея витала в моей голове ещё давно, но руки никак не доходили для создания этого проекта,

так-то уже существует много мостов между максом и telegram но на сколько мне известно, никто из них не использует "форумы"

так-что, своего рода это "уникальный" проект.

## Дисклеймер
maxtgforumsbridge использует готовое неофициальное api [pymax](https://github.com/MaxApiTeam/PyMax) а он в свою очередь использует неофициальный внутренний aoi макса.

api может измениться без предупреждения, и, вследствии чего некоторые функции могут перестать работать без предупреждения. 

**Использование библиотеки и данного моста может нарушать условия сервиса.**

Вы используете PyMax и maxtgforumsbridge на свой риск. **За блокировку аккаунта отвечаете только Вы.**

## Что умеет этот ваш мост?

- 💬 Пересылает сообщения между MAX и Telegram
- 🧵 Создаёт отдельную тему форума для каждого личного чата
- 👥 Для групп MAX использует одну тему и подписывает сообщения именами отправителей
- 🔄 Работает в обе стороны
- 💾 Запоминает соответствие чатов и тем после перезапуска

## Установка

Python 3.11+ рекомендуется.

    python -m venv .venv
    # Windows:
    .venv\Scripts\activate
    # Linux:
    source .venv/bin/activate

    pip install -r requirements.txt

Создай `.env`:

    MAX_PHONE=+70000000000
    TELEGRAM_BOT_TOKEN=token
    TELEGRAM_FORUM_CHAT_ID=-0000000000000
    DB_PATH=data/bridge.sqlite3
